## Context
笠間市の農地分類データ（4特徴量、クラス不均衡 A:156 / B:30）に対し、既存手法（K-Means / Random Forest / SVM）に加えてXGBoostとLightGBMによる精度改善の余地を検証した。

## Decision
現行データセットにおけるアルゴリズム変更およびパラメータ調整はここで打ち切り、Phase 2からの継続性を踏まえて **XGBoost** を現行ベースラインとして採用する（LightGBMでも同等の結果であることを確認済み）。

## Alternatives
XGBoostとLightGBM（`scale_pos_weight` および木の深さ制限を適用）を比較したが、両ライブラリ間で精度差はほぼなく、既存手法が到達していた既知の上限（ROC ≈ 0.80）を超えられなかった。

## Consequences
64次元のAlphaEarth埋め込みを用いた先行リサーチでも同一の上限（ROC ≈ 0.80）に到達しているため、主因はモデルやデータ件数ではなく「10m解像度×極小区画」という物理的限界である可能性が高く、今後の精度向上にはモデル調整ではなく入力データ解像度や対象区画の条件見直しが必要となる。
